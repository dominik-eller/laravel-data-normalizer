# Contributing

Thank you for considering contributing to this project!

## Reporting Issues

Please use the issue tracker on GitHub to report bugs or suggest enhancements. When opening a new issue, provide as much detail as possible about your environment and steps to reproduce the problem.

## Submitting Pull Requests

1. Fork the repository and create your branch from `main`.
2. Make your changes following the existing code style.
3. Run `composer test` to ensure the test suite passes.
4. Submit a pull request and describe your changes.

Pull requests with tests and a clear description are greatly appreciated.
